# Data Science / Учебные проекты магистратуры

Репозиторий с результатами выполнения заданий и учебных проектов во время обучения в магистратуре. Основной формат материалов — Jupyter Notebook (`.ipynb`).

## Что здесь?

Здесь располагаются результаты выполнения заданий по направлениям data science и программирования: ноутбуки с разборами задач, эксперименты с данными и вспомогательные модули.

## Установка и запуск

Проект использует изолированное виртуальное окружение (`venv`). Для воспроизведения:

```bash
python3 -m venv .venv          # создать окружение
source .venv/bin/activate      # активировать (Windows: .venv\Scripts\activate)
pip install -r requirements.txt
```

Затем откройте ноутбук (например, [`game.ipynb`](game.ipynb)) в VS Code и выберите ядро `.venv` в правом верхнем углу. Зависимости проекта перечислены в [`requirements.txt`](requirements.txt).
